# Start/Sit candidate summaries

The summary could show player names under plain START and SIT headings while
the same page explained that holds meant no direct change was ready. The names
are useful comparison evidence, but the headings could look like instructions.

Both summary cards now say START candidate / SIT candidate and show an explicit
review notice when any player hold exists, projection coverage is not FULL, or
changed assignments have an UNVERIFIED status-check time. Full, zero-hold
proposals with a recorded status time retain the existing headings. These are
presentation conditions, not new source verification or availability clearance.
The detailed lineup board uses Candidate starter under the same review
conditions, so its labels agree with the summary cards. Fully supported previews
retain Recommended starter. Current-player labels and comparisons remain.

Proposal names, comparisons, source-proof marker, hold reasons and read-only
boundary remain. No optimizer output, source fetch, transaction or authorization
is changed. Real staged-renderer fixtures cover held/full, zero-hold/full,
partial and unknown projection coverage, and unverified status time, including
the single source-proof paragraph and no-submission notice.
